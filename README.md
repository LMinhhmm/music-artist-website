
# 🎵 Music Artist Website

## 📌 Overview

This project is a web application designed to showcase original songs of an independent artist.

The goal is to provide a platform where users can:

* Discover songs
* Listen to audio (AI-generated recordings)
* Read song lyrics and descriptions

This project is also developed as a **full software development lifecycle (SDLC) practice**, including requirement definition, system design, development, testing, and deployment.

---

## 🎯 Objectives

* Build a simple and scalable music showcase platform
* Practice real-world software development workflow
* Apply Agile-based task management and Git workflow

## 🏗️ Tech Stack

* Frontend: Next.js (React)
